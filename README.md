# Химический визуализатор молекул

Интерактивный веб-проект для визуализации молекулярных структур, сравнения веществ, расчёта молярной массы, количества вещества и интеллектуального анализа химических свойств.

## Описание проекта

«Химический визуализатор молекул» — это учебный веб-модуль, разработанный для наглядного представления химических данных. Пользователь вводит химическую формулу вещества, после чего программа строит его 2D-модель, отображает типы химических связей и выводит основные характеристики молекулы.

Проект демонстрирует, как визуализация данных может применяться в химии для понимания связи между составом вещества, строением молекулы и её свойствами.

## Возможности

- построение 2D-модели молекулы по формуле;
- отображение одинарных, двойных и тройных связей;
- отображение ароматической системы;
- режим показа неподелённых электронных пар;
- выпадающий список молекул;
- вывод тривиального названия и названия по ИЮПАК;
- вывод геометрии, полярности и гибридизации;
- расчёт молярной массы вещества;
- расчёт количества вещества по формуле `n = m / M`;
- сравнение двух молекул;
- прототип интеллектуального анализа свойств молекулы.

## Используемые технологии

Проект реализован с использованием:

- HTML;
- CSS;
- JavaScript;
- Canvas API.

HTML отвечает за структуру страницы, CSS — за оформление интерфейса, JavaScript — за построение молекул, расчёты и интеллектуальный анализ.

## Поддерживаемые молекулы

В текущей версии поддерживаются вещества разных классов:

- простые вещества: `H2`, `O2`, `N2`, `Cl2`;
- неорганические соединения: `H2O`, `NH3`, `HCl`, `H2S`, `H2O2`;
- оксиды: `CO2`, `SO2`, `SO3`, `NO`, `NO2`;
- кислоты: `H2SO4`, `HCN`, `HCOOH`, `CH3COOH`;
- спирты: `CH3OH`, `C2H5OH`;
- углеводороды: `CH4`, `C2H4`, `C2H2`, `C3H8`, `C3H6`, `C6H6`, `C7H8`;
- другие соединения: `HCHO`, `CS2`, `CCl4`.
